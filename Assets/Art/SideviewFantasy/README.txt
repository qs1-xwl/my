【Environments 环境背景】(每个都是独立文件夹, 里面有背景分层+瓦片)
  mist-forest-background     迷雾森林(大树/松树/苔藓石台, 冷色神秘)
  sunny-rocky-mountains      阳光岩石山脉(蓝天/松树/红岩/紫砖建筑)
  forest-road-background     森林小路(前中后分层)
  Day-Platformer             白天横版场景(天空/云/树/瓦片)
  lava-background            熔岩洞窟(岩浆/岩石)
  treasure-hoard-platform    巨龙宝库(金币/岩石)
  ships-graveyard            沉船墓地(海面/远中近船)
  Rocky Beach environment    岩石海滩(海水/沙滩)
  Rocky-Tileset / Modular-tileset / Rocks-Textures / colorful-tileset
                             各种岩石/彩色模块化瓦片
  gems                       宝石关卡(宝石精灵表+关卡瓦片)

【Sprites 生物+特效】
  蘑菇怪/青蛙怪/兔/飞龙/蛇/蜥蜴/鸟/幽灵/BOSS巨龙
  + 攻击特效: slash横斩/纵斩/圆形斩, fire-ball火球, energy-shield护盾
  + 敌人动作: idle/walk/jump/attack/hurt/shoot 等

Unity 用法:
  1. 每个背景文件夹里的 back/middle/front 分层图,
     按层拖进场景, Sorting Order 从远到近依次增大
     (back最远最小, front最近最大)
  2. 瓦片配合 Tilemap 画平台地形
  3. Sprites 里的敌人有全套动作, 直接切帧做动画
