PlayerSwordman  (C1951.zip -> Swordman)

来源：C1951.zip 内的 Swordman 角色，逐帧原样导出，未做任何缩放或改色。
用途：可替换 Player 的美少女剑士素材（近战，持剑）。

目录：
  Idle    待机
  Walk    行走
  Attack  近战出招
  Hurt    受击
  Dead    死亡
  Sing    备用动作（包里叫 sing，可当待机变体或技能动作）

注意：这套素材没有 Jump / Run 动作。跳跃只能复用 Idle 或 Walk 的某一帧。
替换时 Unity 里把新帧拖进对应 .anim 剪辑即可，旧的 Elizabeth 素材不要删。
